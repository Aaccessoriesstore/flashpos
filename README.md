# FlashPOS — نظام الكاشير

> **تنبيه أمني وتشغيلي:** هذه النسخة غير جاهزة للاستخدام في المبيعات الحقيقية. لا تُدخل بيانات عملاء أو مبيعات أو كلمات مرور فعلية.

## حالة التشغيل

واجهة GitHub Pages ليست خادم قاعدة بيانات. يعتمد التطبيق على Supabase، لكن نقطة الاتصال المنشورة لم تكن متاحة عند التحقق، لذلك لا يمكن تأكيد تسجيل الدخول أو حفظ البيانات أو مزامنتها بين الأجهزة. لا تعتبر ظهور صفحة الدخول دليلًا على جاهزية النظام.

## ملاحظة أمنية مهمة

تسجيل الدخول الحالي يستعلم من جدول `app_users` مباشرة من المتصفح ويقارن تجزئة كلمة المرور في العميل. كما أن ملف `supabase_migration.sql` ينشئ سياسات RLS مفتوحة تسمح بالوصول إلى الجداول دون التحقق من المستخدم. لا تشغّل هذه السياسات على قاعدة تحتوي بيانات فعلية، ولا تستخدم إعدادات قاعدة البيانات الحالية في الإنتاج.

قبل أي تشغيل فعلي، يلزم على الأقل:

1. استخدام Supabase Auth أو خادم موثوق للتحقق من المستخدمين بدل مصادقة المتصفح المخصصة.
2. استبدال السياسات المفتوحة بسياسات RLS تختبر هوية المستخدم وصلاحياته، والتحقق منها بحساب مجهول وحساب مصرح.
3. تعطيل وتغيير بيانات الدخول الافتراضية التي سبق نشرها، ومراجعة المستخدمين ومفاتيح المشروع وسجلات الوصول.
4. ضبط عنوان مشروع Supabase ومفتاحه العام الصحيح كإعدادات بناء. لا تضع مفتاح `service_role` أو كلمة مرور في التطبيق أو المستودع.
5. اختبار تسجيل الدخول والبيع وحفظ البيانات والمزامنة بين جهازين قبل استخدام البيانات الحقيقية.
